This dashboard and the live portfolio share one Firestore document.

2

3

API & Sync

This dashboard reads and writes Firebase Firestore — the same document index.html reads on the live portfolio.

1

Every edit auto-syncs

Changes save to this browser immediately, then push to Firestore automatically ~700ms after you stop editing (debounced, so rapid changes collapse into one request).

2

Only signed-in accounts can write

Firestore Security Rules require a valid sign-in (see the login screen) to write this document. Anyone — including portfolio visitors — can read it, but only accounts added under Firebase Authentication → Users can change it.

3

Manage access

Add or remove who can sign in to this dashboard from the Firebase Console → Authentication → Users.
